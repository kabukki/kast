# kast

Calculateur d'impôt sur le revenu — Barème 2026.

TanStack Start (React, SSR) deployed to Cloudflare Workers at https://kast.le-roux.dev.

## Develop

```sh
npm install
npm run dev
```

## Deploy

```sh
npm run deploy
```

Requires `wrangler login` (or `CLOUDFLARE_API_TOKEN` in the environment) once.
